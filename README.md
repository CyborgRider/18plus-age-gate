A highly customizable age gate plugin for posts and pages within your wordpress site.
Optimal for sites that don't want to age gate the whole site, but who have sensitive content on select posts or pages of their site.
This is a custom plugin that I made with the intention of adhering to minimum required age restriction laws in my area, and should only be used if a yes/no prompt is legally permissible in the area you're hosting from.
I write smut sometimes, and wanted to be able to apply a category wide NSFW tag that would apply to any categories or sub-categories that I drop my stories into when writing. 
I wanted to make this open-source and easy to access, so I'm going to be submitting this as an official plugin to Wordpress.org as well as the open source version being available and easy to make changes to from here.

# Features:
1. Pop-up that blocks the user from accessing a post until after they click the affirmative button.
2. Customizable text for the popup from title, to message, to the buttons themselves.
3. Customizable selection of posts by post name, by category/tags, or by pages/parent-page.
4. Customizable redirection; send them to a specific page already on your site, or send them to a custom URL.
5. Customizable timetable for cookies to confirm how long until the user gets a new prompt. Measured in days. Default: 365.

6. Further customization includes the cookie Name. This should only be changed if you believe it would be funny for the guy who sniffs his cookies to see something labeled __you_dirty_boy__ or something to the like. Default is simply smut_verified

# Installation:
Simply download the .zip file and upload to your wordpress site from the admin portal!
